# Подключение синхронизации «Моя прибыль» через Supabase

Синхронизация хранит записи доходов, трат, повторяющиеся доходы, лимиты, напоминания, копилку и цель в закрытой строке Supabase, доступной только вошедшему владельцу.

1. Создайте проект Supabase и скопируйте **Project URL** и публичный **anon/publishable key**. Не используйте `service_role` или секретный ключ в браузере.
2. В Supabase откройте SQL Editor, вставьте содержимое `SUPABASE-SETUP.sql` и выполните запрос.
3. В Authentication → URL Configuration добавьте адрес приложения `https://f87fp7zzhv-dev.github.io/moya-pribyl/` в Redirect URLs.
4. На iPhone и Mac откройте раздел **Доходы → Синхронизация между устройствами**. Сохраните один и тот же Project URL и публичный ключ на каждом устройстве.
5. Введите одну и ту же почту на обоих устройствах и войдите по ссылке из письма.

После входа приложение загружает общие данные и периодически проверяет изменения. Табличные политики разрешают каждому пользователю читать и изменять только собственную строку. Публичный ключ сам по себе не даёт доступа к финансовым данным без входа и политик RLS.
